# The website build

`site/` is a static website that runs hebzip's modes `fast` (Hebrew) and `en_fast` (English) in the
visitor's browser: Pyodide (Python 3.14 in WebAssembly) inside a Web Worker, the package's own code, the
pinned tables. It is served as-is: `.github/workflows/pages.yml` publishes the `site/` folder to GitHub Pages
(Settings -> Pages -> Source: "GitHub Actions"); nothing is built on GitHub.

## What is hand-written and what is generated

Hand-written (edit freely): `site/index.html`, `site/assets/*`, `site/settings.json`
(**`repo` there is the GitHub repository the page links to and shares results with**).

Generated by `python tools/site/build_site.py` from the repository (never edit by hand):

| path | from |
|---|---|
| `site/py/hebzip.zip` | every `.py` file of `hebzip/` (fixed timestamps) |
| `site/py/browser.toml` | `python -m hebzip.ops.config_subset` of `config/hebzip.toml`: modes `fast` + `en_fast`, their tables and language packs, and the `[hebzip]` rows of `tools/site/build.toml` (engine `python`, store `eager`, no fallback). The tool proves each mode signs exactly like the real config, so packages are the same bytes as the CLI's. |
| `site/py/entry.py` | `tools/site/entry.py` (four functions the worker calls) |
| `site/tables/` | the pinned tables of the two modes (sha256 checked; gzipped as `.gz` when that saves 20% or more - the page un-gzips and checks the pinned sha256) + `tables/LICENSE`, `CREDITS.md`, title lists. `--unpack-tables` writes them back into `tables/` for the native tool. |
| `site/samples/` | the two sample texts (project texts from `golden/`) |
| `site/data/bench.json` | the recorded benchmark (`tools/compare_page/bench/results/`) |
| `site/pyodide/` | the Pyodide 314.0.8 core files + the numpy wheel, unmodified, + `tools/site/licences/*` |
| `site/build.json` | every file the page fetches, with size and sha256 (progress bar + integrity check) |

## Commands

    python tools/site/build_site.py --pyodide <folder>   # first time: copy Pyodide from its release folder
    python tools/site/build_site.py                      # after a code / table / bench change
    python tools/site/build_site.py --check              # exit 1 if site/ differs from a fresh build
    python tools/site/build_site.py --unpack-tables      # the website's tables -> tables/ (native fast / en_fast)
    python tools/site/run_tests.py                       # the build's tests

The Pyodide folder is the unpacked `pyodide-core-314.0.8` release (https://github.com/pyodide/pyodide/releases)
plus the numpy wheel named in its `pyodide-lock.json`.

## Privacy, by construction

The page has a Content-Security-Policy that allows connections to its own origin only; every URL in the code
is relative. There are no cookies and no analytics. The only place that leaves the site is the
*Share your result* link to GitHub, opened by the visitor after a preview of exactly what it carries
(numbers only). The language-pack choice is made from letter counts in the browser.

Loading: the engine (16.7 MB) and the Hebrew pack (12.5 MB) load first; the English pack (6.9 MB) then
downloads in the background - or only when needed, if the browser reports a data-saving or cellular
connection. Browsers keep the files in their normal HTTP cache. There is no service worker.
